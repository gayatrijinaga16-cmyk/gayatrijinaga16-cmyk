## Featured Projects

### 1. OLA Ride-Sharing Data Analysis

**Tech:** MySQL · SQL · Power BI · DAX

- Analyzed **20,407 OLA ride bookings** across **7 vehicle types and 4 payment methods**.
- Wrote **10 MySQL queries and views** (filtering, GROUP BY, AVG/SUM/MAX/MIN aggregations).
- Built a **5-page Power BI dashboard** (Overall, Vehicle Type, Revenue, Cancellation, Ratings) with **5 DAX KPIs** and a date slicer.
- Found that **62%** of bookings succeeded, while **17.91%** were cancelled by drivers, **10.2%** by customers, and **9.9%** had no driver found.

[**View OLA project repository →**](https://github.com/gayatrijinaga16-cmyk/OLA-Ride-Sharing-Data-Analyst-Project)

### 2. Mobile Sales Performance Dashboard

**Tech:** Power BI · Data Visualization · KPI Analysis

- Analyzed **3,835 transactions (19,150 units, INR 769M in sales)** across **5 brands and 19 cities**.
- Built 4 KPI cards, monthly quantity trends, sales by day of week, mobile model and payment method, plus a city-level map.
- Apple ranked first by revenue (INR 161.6M), narrowly ahead of Samsung (INR 160.0M).

[**View Mobile Sales project repository →**](https://github.com/gayatrijinaga16-cmyk/Mobile-Sales-Data-Analysis-Project)

### 3. Retail Customer Behavior and Shopping Trends Analysis

**Tech:** Python · Pandas · SQL · Power BI

- Cleaned and restructured **3,900 customer records** using Python and Pandas.
- Built a Power BI dashboard showing 3.9K customers, $59.76 average purchase amount and 3.75 average review rating, with revenue by category and gender.

[**View Retail project repository →**](https://github.com/gayatrijinaga16-cmyk/Retail-Customer-Shopping-Behavior-Analysis-Data-Analysis-Project)

### 4. Heart Disease Data Analysis Dashboard

**Tech:** Power BI · DAX · Data Visualization

- Analyzed **299 patient records**: 203 (67.89%) alive and 96 (32.1%) with a death event.
- Built KPI cards with DAX measures and charts of survivors, diabetes cases and average serum sodium by age group, with a gender slicer.

[**View Heart Disease project repository →**](https://github.com/gayatrijinaga16-cmyk/Heart-Disease-Data-Analyst-Project)
